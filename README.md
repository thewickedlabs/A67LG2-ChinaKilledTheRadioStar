# A67LG2 ChinaKilledTheRadioStar

FM radio through the speaker, no headphones needed.

A KernelSU Next module for the **Foxxd A67L Gen 2**. Gen 1 version: [A67LG1-ChinaKilledTheRadioStar](https://github.com/thewickedlabs/A67LG1-ChinaKilledTheRadioStar).

The FM radio normally needs wired headphones as an antenna. This module turns on the phone's built-in
short-antenna mode, so the radio plays through the speaker on its own. Reception uses the internal
antenna, so it's weaker than with a headphone cable.

Tap **Action** on the module in KernelSU Next to switch it on or off without rebooting (reopen the
FM Radio app afterwards).

## Requirements

- Foxxd A67L Gen 2
- Rooted with KernelSU Next

The installer stops without changing anything if either is missing.

## Install

1. Download [`A67LG2-ChinaKilledTheRadioStar.zip`](https://github.com/thewickedlabs/A67LG2-ChinaKilledTheRadioStar/releases/latest/download/A67LG2-ChinaKilledTheRadioStar.zip) (latest release).
2. KernelSU Next → Modules → Install from storage → select the zip.
3. Reboot.

## Uninstall

Disable or remove the module and reboot.
